## 🎨 Spécifications Techniques

### Formats
- **Format principal:** JPG (qualité 85%)
- **Format alternatif:** WebP (pour optimisation)
- **Résolution:**
  - Hero images: 1920x1080px minimum
  - Cards/Sections: 800x600px
  - Mockups: 1200x800px

### Optimisation
```bash
# Après téléchargement, optimiser avec:
npm install -g sharp-cli
sharp -i input.jpg -o output.jpg --quality 85 --progressive
```

### Nommage
- Tout en minuscules
- Mots séparés par tirets
- Descriptif et clair
- Exemple: `forest-aerial-monitoring.jpg`

## 📋 Instructions de Téléchargement

### Méthode 1: Manuelle (Recommandée pour qualité)

1. Aller sur Unsplash
2. Chercher l'image avec mots-clés
3. Cliquer sur "Download free"
4. Renommer selon convention
5. Placer dans dossier approprié
6. Optimiser avec Sharp

### Méthode 2: Script Automatique

```bash
# Créer script download-images.sh
#!/bin/bash

# Hero images
cd public/images/hero
curl -L "https://images.unsplash.com/photo-[ID]?q=85&w=1920" -o earth-space-view.jpg

# Satellites
cd ../satellites
curl -L "https://images.unsplash.com/photo-[ID]?q=85&w=800" -o satellite-1.jpg

# Continuer pour chaque image...
```
